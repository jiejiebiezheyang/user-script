## 安装方法

1. 为你的浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 点击上表中脚本对应的**安装**链接，Tampermonkey 会弹出安装提示。
3. 确认安装后，打开任意视频页面即可使用。

手动安装：打开对应的 `.js` 文件，复制其内容，粘贴到 Tampermonkey 管理面板的新建脚本中即可。
