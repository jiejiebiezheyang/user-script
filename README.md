## Installation

1. Install the [Tampermonkey](https://www.tampermonkey.net/) extension for your browser.
2. Open the **Install** link of the script you want in the table above — Tampermonkey will prompt you to install it.
3. Confirm, then open any video page and enjoy.

To install manually: open the `.js` file, copy its contents, and paste them into a new script in the Tampermonkey dashboard.
